## 1. 前置条件

- 注册一个 [GitHub](https://github.com) 账号
- 把账号名发给仓库管理员，让对方在仓库 **Settings → Collaborators** 中邀请你
- 接受 GitHub 发来的邀请邮件（或打开仓库页面，点击顶部的邀请通知）
- 本机安装 [Git](https://git-scm.com/downloads)（Windows 用户建议选 Git Bash）

## 2. 生成 SSH 密钥

### 2.1 打开终端

| 系统 | 操作 |
|------|------|
| Windows | 右键开始菜单 → **Windows PowerShell** 或 **Git Bash** |
| macOS | `Cmd + Space` 搜索 **Terminal** |
| Linux | 直接打开终端 |

### 2.2 生成密钥（如果没有的话）

```bash
ssh-keygen -t rsa -b 4096 -C "你的GitHub邮箱@example.com"
```

- `-t rsa`：密钥类型为 RSA
- `-b 4096`：密钥长度 4096 位（更安全）
- `-C`：注释，填你的 GitHub 注册邮箱

### 2.3 一路回车

```
Enter file in which to save the key (/Users/you/.ssh/id_rsa):   ← 直接回车
Enter passphrase (empty for no passphrase):                      ← 直接回车（或设置密码）
Enter same passphrase again:                                     ← 再次回车
```

> **提示**：设置 passphrase 更安全，但每次推送都要输入。新手建议先留空。

### 2.4 检查密钥是否生成成功

```bash
ls ~/.ssh/
```

看到 `id_rsa`（私钥）和 `id_rsa.pub`（公钥）就说明成功了。

## 3. 添加 SSH 公钥到 GitHub

### 3.1 复制公钥内容

**Windows PowerShell：**
```bash
cat ~/.ssh/id_rsa.pub
```

**Git Bash / macOS / Linux：**
```bash
cat ~/.ssh/id_rsa.pub
```

输出是一长串以 `ssh-rsa` 开头、以你的邮箱结尾的文本，**全选复制**。

### 3.2 添加到 GitHub

1. 登录 GitHub，点击右上角头像 → **Settings**
2. 左侧菜单 → **SSH and GPG keys**
3. 点击绿色按钮 **New SSH key**
4. 填写：
   | 字段 | 内容 |
   |------|------|
   | Title | 随意取名，如 `公司台式机` 或 `MacBook Pro` |
   | Key type | 选 **Authentication** |
   | Key | 粘贴刚才复制的公钥 |
5. 点击 **Add SSH key**
6. 输入 GitHub 密码确认

### 3.3 验证连接

```bash
ssh -T git@github.com
```

看到 `Hi <你的用户名>! You've successfully authenticated...` 即表示成功。

> 首次连接会提示 `Are you sure you want to continue connecting?`，输入 `yes` 回车。

## 4. 克隆仓库到本地

### 4.1 为什么要用 `git clone` 而不是 `git init`？

| 命令 | 用途 | 场景 |
|------|------|------|
| `git init` | 在本地**从零创建**一个新仓库 | 你自己新建一个项目，初始化 Git 后再推到 GitHub |
| `git clone` | 把远程**已有仓库**完整复制到本地 | 加入团队项目，仓库已经存在于 GitHub 上 |

团队成员不需要 `git init`，`git clone` 一条命令就帮你完成了：

- 初始化本地仓库（相当于 `git init`）
- 关联远程仓库（相当于 `git remote add origin`）
- 拉取全部代码和历史（相当于 `git fetch`）
- 切换到主分支（相当于 `git checkout main`）

> **一句话**：`git init` = 你自己做新项目；`git clone` = 加入别人的已有项目。

### 4.2 选择存放代码的工作文件夹

首先决定代码放在哪里。建议选一个**容易找到、路径不含中文**的位置，例如：

| 系统 | 推荐路径 |
|------|----------|
| Windows | `D:\workspace\` 或 `C:\Users\你的用户名\projects\` |
| macOS | `/Users/你的用户名/Desktop/` 或 `/Users/你的用户名/projects/` |
| Linux | `/home/你的用户名/projects/` |

### 4.3 执行克隆

打开终端，进入你选择的工作文件夹：

```bash
# 例如你决定把代码放在 D:\workspace，终端中输入：
cd /d/workspace

# 克隆仓库（下面的地址改成你们仓库的 SSH 地址）
git clone git@github.com:yiamll930-hue/Water-Observe-and-Search.git
```

克隆过程中你会看到：
```
Cloning into 'Water-Observe-and-Search'...
remote: Enumerating objects: 10, done.
remote: Counting objects: 100% (10/10), done.
remote: Compressing objects: 100% (8/8), done.
Receiving objects: 100% (10/10), done.
```

### 4.4 进入项目目录

```bash
cd Water-Observe-and-Search
```

现在可以查看项目内容了：

```bash
ls          # 列出所有文件
git status  # 查看当前状态
git log     # 查看提交历史
```

> **注意**：如果你的工作文件夹路径包含中文（如 `D:\工作\项目\`），某些工具可能出现编码问题，建议用全英文路径。

## 5. 日常开发流程

### 5.1 开发前先同步最新代码

```bash
git checkout main
git pull origin main
```

### 5.2 创建自己的功能分支

```bash
# 从 main 创建新分支，分支名用英文描述功能
git checkout -b feature/你的功能名

# 例如：
git checkout -b feature/add-login
git checkout -b fix/typo-in-readme
```

### 5.3 写代码，提交

```bash
# 查看改了哪些文件
git status

# 添加修改的文件
git add .

# 提交（commit message 写清楚做了什么）
git commit -m "添加了登录页面"

# 推送到远程
git push -u origin feature/你的功能名
```

### 5.4 发起 Pull Request（PR）

1. 打开仓库页面：https://github.com/yiamll930-hue/Water-Observe-and-Search
2. 通常会看到黄色的 **Compare & pull request** 提示，点击它
3. 写清楚这个 PR 做了什么改动
4. 点击 **Create pull request**
5. 通知管理员审核，审核通过后会合并到 `main`

### 5.5 PR 合并后清理本地

```bash
git checkout main
git pull origin main
git branch -d feature/你的功能名        # 删除本地分支
```

## 6. 常见问题排查

### Q1: `Permission denied (publickey)`

**原因**：SSH 密钥没配好或没添加到 GitHub。

**解决**：
```bash
# 先测试连接
ssh -T git@github.com

# 如果失败，检查密钥是否存在
ls ~/.ssh/

# 确保公钥已添加到 GitHub（见第 3 节）
```

### Q2: `Could not read from remote repository`

**原因**：没有仓库权限。

**解决**：确认管理员已经把你添加为 Collaborator，并且你已经**接受了邀请**。

### Q3: 拉取时提示 `Please enter a commit message`

**原因**：`git pull` 需要合并远程和本地的改动。

**解决**：终端会打开 vim 编辑器让你输入 merge message，直接：
- 按 `Esc`
- 输入 `:wq` 然后回车

如果不想进 vim，可以换用：
```bash
git pull --no-edit
```

### Q4: `failed to push` / `rejected`

**原因**：远程有你本地没有的新提交。

**解决**：先拉取再推送：
```bash
git pull origin main
git push origin main
```

### Q5: `unrelated histories`

**原因**：本地和远程是两个独立的 Git 历史。

**解决**：
```bash
git pull origin main --allow-unrelated-histories
```
